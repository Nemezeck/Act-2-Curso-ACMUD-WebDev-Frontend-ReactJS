# Actividad 2 - useState y useEffect

Curso ACMUD WebDev Frontend - ReactJS

Tres ejemplos cortos:

- **Contador**: `useState` para el número y `useEffect` que actualiza el título de la pestaña cuando cambia.
- **Reloj**: `setInterval` dentro de un `useEffect`, con la función de limpieza (`clearInterval`) al pausar o desmontar.
- **Usuarios**: `fetch` a JSONPlaceholder cuando el componente se monta (arreglo de dependencias vacío), con estados de carga y error, y un input controlado para filtrar.

## Cómo correrlo

```
npm install
npm run dev
```

Hecho con React 19 y Vite.
